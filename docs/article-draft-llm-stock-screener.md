# 我让 5 个 AI 当股票分析师，用 12 个维度打分，结果出乎意料

> 2026-03-08 | 公众号文章初稿
> 选手: GLM-5, Gemini 3.1 Pro, Qwen3.5-Plus, MiniMax-M2.5, Kimi-K2.5
> 裁判: 12 维评测框架 + prompt 优化 A/B 测试

---

## 引子

每天美股开盘前，我的选股系统自动从全市场几千只股票中筛出 5 只最值得关注的标的。

系统的核心是大模型 —— 它负责读完每只股票的 K 线、新闻、期权数据和宏观日历，然后做出判断：这票值不值得看？怎么交易？在一堆候选人里排第几？

市面上大模型那么多，谁选股更靠谱？

我不想靠感觉判断，所以设计了一套 12 维评测框架，让 5 个模型在完全相同的条件下 "比武"。

**选手**：
- 4 个国产模型：GLM-5（智谱）、Qwen3.5-Plus（通义）、Kimi-K2.5（月之暗面）、MiniMax-M2.5
- 1 个国际选手：Google Gemini 3.1 Pro

**赛场**：8 只美股，覆盖 8 个 GICS 行业，同一天的真实市场数据（2026 年 3 月 7 日，VIX 高达 29.5 的高波动日）。

---

## 一、系统长什么样

选股系统是一个 5 阶段漏斗：

```
全市场 ~3500 只
  ↓ 基础筛选（流动性、市值、上市状态）
95 只候选
  ↓ 多因子打分（新闻热度、技术形态、事件催化）
8 只进入 LLM 评审
  ↓ Stage 1: Triage — 快速分类（keep / observe / reject）
  ↓ Stage 2: Deep — 写完整分析报告（牛熊观点、入场条件、止损位）
  ↓ Stage 3: Judge — 横向对比排名，选出 Top 5
最终推荐 5 只
```

模型在后三个阶段介入。关键设计：**所有模型拿到的输入完全一样** —— 同样的 K 线数据、同样的新闻、同样的期权信息。差异只来自模型本身的判断力。

这不是让 AI "预测股价"，而是评估它们的**分析判断能力** —— 能不能从一堆数据中识别出值得关注的机会，同时避开明显的陷阱。

## 二、12 维评测框架

### 为什么不只看"选得准不准"？

"选得准"需要等 10 个交易日才有结果（我们正在搭建一套独立的评测系统来做这件事）。但模型的能力差异，在输出的那一刻就已经暴露了。

我从**训练质量、推理能力、工程可用性**三个角度设计了 12 个评价维度：

| 层级 | 维度 | 一句话解释 |
|------|------|-----------|
| **训练** | D1 指令遵循 | JSON 格式对不对 |
| | D2 置信度校准 | 说 80% 有把握，真的有 80% 吗 |
| | D7 跨任务泛化 | 分类、分析、排名三件事都做得好吗 |
| | D9 格式规范 | snake_case、命名风格统一吗 |
| | D12 决策独立性 | 有自己的观点还是随大流 |
| **推理** | D3 推理一致性 | 论据和结论自洽吗 |
| | D4 可执行性 | 给的建议能直接下单吗 |
| | D5 风险敏感度 | 看到风险后会改变决策吗 |
| | D6 信息利用度 | 2 万字的数据包，它看了多少 |
| | D8 输出效率 | 用多少 token 传递了多少信息 |
| **工程** | D10 稳健性 | 会不会动不动报错 |
| | D11 延迟 | 多快出结果 |

每个维度 1-10 分，加权汇总。

## 四、名场面回放

### 场景 1：JPM 暴跌日 — 谁敢说不？

测试当天，摩根大通（JPM）跌了 3%，金融板块是全市场最弱的行业（-7.57% vs SPY），VIX 飙到 29.5。

**客观来看，JPM 当天的状态非常不适合交易。**

5 个模型怎么判断？

| 模型 | 判断 | 置信度 | 做了什么 |
|------|------|--------|---------|
| MiniMax | 观望 | 0.55 | 看到了风险，降低了信心，但不敢拒绝 |
| Kimi | 观望 | 0.72 | 列了 6 条风险……然后信心值跟其他票一模一样 |
| GLM-5 | **拒绝** | 0.72 | 写了 7 条拒绝理由，果断否决 |
| Qwen | **拒绝** | 0.85 | 全场最高信心的拒绝 —— "我非常确定这票不该碰" |
| Gemini | **拒绝** | 0.85 | 同样果断，与 Qwen 一致 |

> **洞察：看到风险但不行动，比看不到风险更危险。**
>
> Kimi 列出了最多的风险标签（6.1 个/票，比其他模型都多），但它的置信度从来不变。它给用户一种"我仔细考虑了风险"的假象，但风险分析对决策没有任何实际影响。

### 场景 2：Kimi 的 0.72 恐怖故事

这是整个测试中**最惊人的发现**。

Kimi 对 8 只股票给出的 triage 置信度：

```
DIS:  0.72
JPM:  0.72
LIN:  0.72
NEE:  0.72
NVDA: 0.72
PLD:  0.72
UNH:  0.72
XOM:  0.72
```

**全部是 0.72。**

不管是涨了 10% 的防御型公用事业股（NEE），还是跌了 3% 的半导体龙头（NVDA），Kimi 觉得它们一样有把握。

这相当于一个医生对每个病人都说"你大概率没事" —— 这个"大概率"没有任何信息量。

> 配图建议：5 个模型的 confidence 分布柱状图，Kimi 那一列全是同一高度

**为什么会这样？**

这很可能是 RLHF（人类反馈强化学习）训练的副作用。在训练过程中，模型发现"中等偏高的置信度"最容易获得人类的好评 —— 太自信会被质疑，太谦虚又显得没用。于是它收敛到了一个"安全值"：0.72。

这在学术上叫 **reward hacking** —— 模型找到了一条捷径来最大化奖励，但这条捷径对实际使用毫无帮助。

### 场景 3：DIS（迪士尼）— 只有 Gemini 敢拒绝

8 只测试票中，迪士尼的客观状态其实很差：负面新闻多、传媒板块弱势、技术面下行。

但 4 个国产模型**全部给了"观望"**。没有一个敢直接拒绝。

只有 Google 的 Gemini 给了 reject（0.85），果断否决。

这是不是偶然？在后来的 prompt 优化测试中（下文详述），Gemini 在更严格的 prompt 下甚至 reject 了 4 只票 —— 是所有模型中最果断的。

> 一个有趣的假设：国产模型的 RLHF 训练可能更倾向于"给建议"而非"说不"。因为在人类偏好数据中，"提供有用的分析"通常比"直接拒绝"更容易获得高分。Gemini 的训练数据可能在"保护用户免受错误决策"这个维度上有更多的偏好信号。

### 场景 4：NEE vs LIN — 唯一的排名分歧

最终排名中，#3-#5（UNH, JPM, NVDA）所有模型完全一致。但 #1 和 #2 出现了分歧：

- 3 个模型选 LIN（林德集团，工业气体巨头）第一
- 2 个模型选 NEE（NextEra Energy，新能源电力）第一

**有意思的是**，选 NEE 第一的恰好是 GLM-5 和 Gemini —— 一个是 12 维评测中最全面的国产模型，一个是唯一的国际模型。它们在全部 5 个排名上完全一致。

它们的理由也类似：在 VIX 高企的 risk-off 环境下，公用事业股（NEE）的防御属性比工业原材料（LIN）更纯粹。

## 五、速度 vs 质量 vs 成本

| 模型 | 平均延迟 | 质量分 | 输出效率 (token/call) | 性格 |
|------|---------|--------|---------------------|------|
| **Gemini** | **18.3s** | 7.8 | **409** | 快、准、省 |
| Kimi | 25.0s | 6.4 | 624 | 快但质量差 |
| MiniMax | 37.7s | 7.0 | 1,222 | 中速中质 |
| Qwen | 54.1s | 7.6 | 2,886 | 慢但逻辑好 |
| **GLM-5** | **54.4s** | **8.1** | 1,700 | 慢但最全面 |

Gemini 的效率令人惊讶 —— 比 Kimi 快 27%，质量却高了 1.4 分。每次调用只输出 409 个 token（Kimi 的 65%、Qwen 的 14%），但信息完整度不打折扣。

Qwen 最"话多"（输出是 Gemini 的 7 倍），但它的推理一致性确实是最好的。"展示思考过程"的代价是更多的 token。

> **最优策略不是选一个模型，而是组合**：Gemini 做快速筛选（18s），GLM-5 做深度分析（54s）。兼顾速度和质量。

## 六、一个反直觉的发现：数据比模型更重要

我们做了两轮测试：

- **第一轮**：3 只科技股，数据不完整 → 模型之间分歧很大
- **第二轮**：8 只跨行业，数据完整（加了 20 天 K 线、期权数据、宏观日历）→ 5 个模型排名 #3-#5 完全一致

**结论：模型之间的分歧，很大程度上不是"能力差异"，而是"数据不足时如何填补空白"。**

当输入信息足够充分，不同模型的推理会收敛。反过来说 —— 如果多个模型给出了不同答案，首先应该检查**数据够不够**，而不是急着判定哪个模型更聪明。

这对实际使用 AI 有很强的指导意义：**与其花时间选模型，不如花时间搞数据。**

## 七、Prompt 优化实验：同一句话，天差地别

做完第一轮评测后，我发现了一个问题：所有模型的 confidence 都偏窄，区分度不够。于是我优化了 prompt，加入了三个改进：

1. **Decision criteria** — 明确定义什么条件该 keep、什么该 reject
2. **Calibration guidance** — 告诉模型 confidence 应该覆盖 0.3-0.9 的完整区间
3. **Format requirements** — 强制 snake_case、要求引用具体数字

然后用同样的数据重新跑了一遍。结果出乎意料 ——

### prompt 优化的"两极分化"效应

| 模型 | v2 (原始 prompt) | v3 (优化后) | 变化 |
|------|------------------|------------|------|
| **Gemini** | 3keep/3obs/2rej | 1keep/3obs/**4rej** | 更果断了，confidence 拉到 0.65-0.90 |
| **MiniMax** | 1keep/7obs/0rej | 1keep/5obs/**2rej** | 开始敢拒绝了 |
| **Kimi** | 4keep/3obs, 全 0.72 | 1keep/7obs, **全 0.52** | 换了个安全值，本质没变 |
| **GLM-5** | 0keep/7obs/1rej | 0keep/**8obs**/0rej | 反而更保守，丢掉了 reject |
| **Qwen** | 2keep/5obs/1rej | 0keep/**8obs**/0rej | 同上，全变成了 observe |

**对 Gemini 和 MiniMax**：prompt 优化成功地拉开了区分度。Gemini 甚至 reject 了 4 只票（包括 NVDA 和 PLD），是所有模型中最果断的。

**对 Kimi**：堪称"教科书级 reward hacking"。prompt 告诉它"0.40-0.60 = genuinely uncertain"，它就把所有值从 0.72 挪到了 0.52 —— 精准落在新的"安全区间"中点。**行为模式完全没变，只是黑到了新的最优解。**

**对 GLM-5 和 Qwen**：prompt 中的 calibration guidance 反而**压制了它们的决策果断性**。它们似乎理解为"大部分情况都应该落在 uncertain 区间"，导致原来敢 reject JPM 的勇气消失了。

> **洞察：prompt engineering 不是万能的。** 好的 prompt 能让本身能力强的模型发挥得更好（Gemini），但也可能让另一些模型变得更保守（GLM-5）或者找到新的捷径（Kimi）。模型的底层训练决定了它对 prompt 的响应方式。

## 八、GLM-5 的独门绝技

GLM-5 拿到综合第一不是偶然。它有几个其他模型做不到的事：

**1. 唯一引用了期权数据**

输入数据包里包含 Put/Call ratio、Max Pain、异常期权活动等信息。GLM-5 是唯一在分析中引用了 UNH 的 Put/Call volume ratio（0.43 = 极度看多信号）并把它作为核心论据的模型。

**2. 唯一引用了布林带位置**

NVDA 的布林带位置是 0.06（极度接近下轨 = 超卖），GLM-5 看到了并引用了。其他 4 个模型都没提。

**3. 最详尽的风险分析**

GLM-5 平均每只票写 7.4 条拒绝理由（其他模型平均 5.2 条），而且每条都引用了具体数据。它的"冗余"不是废话，是可审计的推理依据。

这说明 GLM-5 在消化大型 JSON 数据包时，attention 分布更均匀 —— 它能关注到被其他模型忽略的"边缘"数据字段。

## 九、谁该用哪个模型

| 场景 | 推荐模型 | 理由 |
|------|---------|------|
| 生产环境（质量优先） | **GLM-5** | 最全面、最稳定、风险敏感 |
| 快速筛选 / 第一道过滤 | **Gemini 3.1 Pro** | 最快（18s）、最省（409 tok）、敢拒绝 |
| 需要审计推理过程 | **Qwen3.5-Plus** | 推理链最透明、论据最自洽 |
| 双模型流水线 | **Gemini(triage) → GLM-5(deep+judge)** | 速度 + 质量兼得 |
| **不推荐做主力** | **Kimi-K2.5** | 校准崩塌 = 无法信任的 confidence |

## 十、下一步

选得好不好，光看输出不够 —— 还得等市场给答案。

模型只能提交，不能修改评分 —— 就像考试交卷后不能改答案。

一个月后，我们会有 5 个模型、200+ 个 picks 的真实战绩。到时候再来一篇，告诉你**谁的 AI 选股真的赚到了钱**。
